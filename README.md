# Publications

Scientific and technical publications from Kronos Fusion Energy — the 2026 design series.

- `index.html` — Research & Publications index (Complete Volume + the five parts)
- `complete.html` — the complete bound volume
- `breeder.html`, `generator.html`, `magnets.html`, `direct-energy-conversion.html`,
  `ai-quantum-control.html` — one page per paper, each linking its manuscript to the
  data-and-code deposit (Zenodo DOI), the interactive 3D model, and the live verification simulator
- `papers/` — the PDFs (Open Access, CC BY 4.0)
- `build_publications.py` — static generator; regenerate with `python3 build_publications.py`

All five deposits are archived in the Kronos Fusion Energy Zenodo community. No financial or
commercial information appears in this repository.
